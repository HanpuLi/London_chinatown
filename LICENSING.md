# Licensing and data provenance

This repository contains materials with different rights status. No single blanket licence should be inferred from the repository being public.

## OpenStreetMap-derived data

The source dataset is derived from OpenStreetMap. OpenStreetMap data is made available under the Open Database License (ODbL); attribution and share-alike requirements for derivative databases may apply. See the OpenStreetMap Foundation licensing material for the authoritative terms.

## Analysis code and authored outputs

Unless a file says otherwise, no separate open-source licence grant is currently made for the R scripts, authored reports, prose, generated charts, or site design. Public source availability does not itself grant permission to relicense them.

## Third-party images

Files such as `visualizations/Chinese-freemasons-1-726x445.jpg` and `visualizations/IMG_4175.HEIC` may have rights or provenance distinct from the authored analysis. They are not relicensed by this repository. Their provenance should be verified before redistribution or reuse.
