📋 Methodology

Data Collection

  • Source: OpenStreetMap (OSM) data via Overpass API
  • Boundary: KML coordinates provided by user + 50-meter buffer
  • Filtering: Food and beverage establishments only (restaurant, cafe, bar, pub, fast_food, ice_cream, bakery, confectionery, pastry, food)
  • Coordinates: Real OSM coordinates, not simulated

Data Processing

  • Cuisine Consolidation: Merged all Chinese-related cuisines (Taiwanese, Sichuan, Cantonese, etc.) into "Chinese" category
  • Cultural Classification: Multi-dimensional approach using name, cuisine, Chinese name (name.zh), and business type
  • Quality Control: Removed non-business amenities (theatre, casino, etc.) and entries with missing essential data
  • Inference: Applied intelligent cuisine inference for entries with missing cuisine data

Analysis Framework

  • Diversity Indices: Simpson and Shannon diversity indices for cultural and cuisine diversity
  • Visualization: Interactive maps, pie charts, and bar charts for comprehensive data presentation
  • Geographic Precision: KML-based boundary definition with spatial filtering
